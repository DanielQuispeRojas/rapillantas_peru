# Sesión 01 — Inicialización del Proyecto

**Fecha:** 09/09/2026
**Estado:** Completada

---

## Objetivo
Establecer las bases normativas del proyecto RAPILLANTAS y crear la estructura de gestión de contextos entre sesiones.

---

## Decisiones Tomadas

### 1. Marco Normativo
Se definen las siguientes normas como pilares del proyecto:

- **ISO/IEC/IEEE 12207:2017** — Procesos de ciclo de vida del software
  - Proporciona el marco de procesos de software (adquisición, suministro, desarrollo, operación, mantenimiento).
  - Define actividades y tareas alineadas con los procesos del ciclo de vida.

- **ISO/IEC/IEEE 15288:2023** — Procesos de ciclo de vida del sistema
  - Integra la perspectiva de sistema (hardware + software + datos).
  - Define procesos de agreements, interacción, organización, técnica y mejora.

- **ISO/IEC/IEEE 29148:2018** — Ingeniería de requisitos
  - Estandariza BRS/StRS/SRS y trazabilidad.
  - Define plantillas, estructura y requisitos de calidad documental.

### 2. Estructura de Contextos
Se crea la carpeta `contexto-sesiones/` para:
- Almacenar el contexto general del proyecto (`contexto-general.md`).
- Registrar cada sesión de trabajo (`sesion-XX.md`).
- Mantener la continuidad y trazabilidad en futuras sesiones.
