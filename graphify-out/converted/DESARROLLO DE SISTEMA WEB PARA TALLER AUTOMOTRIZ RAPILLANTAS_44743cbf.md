DESARROLLO DE SISTEMA WEB PARA TALLER AUTOMOTRIZ RAPILLANTAS
- Introducción
- Rapillantas es una empresa automotriz dedicada a la venta de refacciones y servicios preventivos/correctivos para coches.

- El presente sistema web permitirá a la empresa gestionar sus tareas administrativas básicas y publicar sus catálogos al publico consumidor de la ciudad de Huancayo
- Actores
- ACT-001 Administrador de Lima.
- ACT-002 Supervisor.
- ACT-003 Administrador Huancayo
- ACT-004 Mecanico
- Necesidades
- NEC-001 El usuario necesita realizar control de stock
- NEC-002 El usuario necesita registrar adquisiciones (orden de compra - OC)
- NEC-003 El usuario necesita poder ver los registros de adquisiciones (orden de compra - OC)
- NEC-004 El usuario necesita asignar margen de ganancia por producto
- NEC-005 El usuario necesita registrar ventas
- NEC-006 El usuario necesita ver registro de ventas
- NEC-007 El usuario necesita ver las tendencias de ventas
- NEC-008 El usuario necesita tener acceso a los expedientes técnicos de vehículos clientes
- NEC-009 El sistema debe avisar al cliente cada 10000 km para mantenimientos pertinentes
- NEC-010 El sistema debe registrar ordenes de Servicio (OS)
